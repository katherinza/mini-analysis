# Music Store Analysis

Проект представляет собой комплексный анализ учебной базы данных музыкального магазина с использованием Python, SQL и Git. В ходе работы выполнена полная цепочка действий: от подключения к базе и написания SQL-запросов различной сложности (JOIN, GROUP BY, подзапросы, CTE, оконные функции) до визуализации ключевых бизнес-метрик с помощью matplotlib или seaborn.

Основные этапы проекта:

- Изучение структуры БД и выполнение практических заданий на выборку данных.
- Углублённый анализ с использованием продвинутых SQL-техник (CTE, RANK, LAG).
- Построение ≥4 информативных визуализаций (столбчатые и круговые диаграммы, тепловые карты, scatter plots), отражающих топ исполнителей по выручке, квартальную динамику продаж, эффективность агентов поддержки, разнообразие жанров в плейлистах и средний LTV покупателей по странам.
- Оформление результатов в итоговый отчёт final_report.ipynb с текстовыми выводами и численными показателями.
- Организация версионирования кода в Git с созданием тематических веток (feature/analysis, feature/visualization) и публикацией на GitHub.
